当前可用方式

如果问题涉及某条公开事件、某类异常、某个 KPI 或标准条款，请优先在 GitHub Issue 中提出。这样问题、来源、讨论和后续修订都能被公开追踪。

正式交互式问答恢复后，本页会改回 AI 问答入口。

建议提问格式

  • 先说明问题背景，例如具体事件、标准条款或运营模式。
  • 附上来源链接或文件名，便于复核证据。
  • 说明希望得到的输出：分类判断、KPI 建议、责任矩阵映射、案例复盘或标准条款建议。
